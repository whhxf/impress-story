# 实现与验收

## 引擎边界与版本

已核验的核心能力：`.step`、`data-x/y/z`、`data-scale`、`data-rotate[-x/-y/-z]`、根节点转场时长、`init/next/prev/goto`、`impress:stepenter` 与 `impress:stepleave`。以当前项目固定版本的源文件/文档为准，不假设所有插件或参数跨版本一致。

官方来源：
- https://github.com/impress/impress.js/
- https://github.com/impress/impress.js/blob/master/DOCUMENTATION.md
- https://github.com/impress/impress.js/blob/master/src/plugins/README.md

新作品优先使用assets/runtime中随Skill保存并带许可的已用运行时；assets/runtime/source.json记录摘要及已知版本信息。不要仅凭文件名推断版本。更换或新增依赖时遵循目标环境网络规则，核验来源并保存许可。插件只引入确实需要的部分，并验证与核心版本兼容。无依赖或网络不可用时明确阻碍，不能以自写 transform 冒充 impress.js。

## 实现约定

- 场景 ID 稳定，导航引用 ID，避免仅靠易变数组下标。默认讲述路径明确；问答跳转后下一步/返回去向应可预测。
- 指定目标设计尺寸；step 使用明确像素尺寸。引擎整体缩放不等于响应式排版。超出窄屏可读范围时提供阅读模式或专门布局。
- 注意相对定位插件可能继承上一 step 的坐标。需要归零时显式设置；不要假定缺省都是零。
- 使用 `goto(id, duration)` 实现节点跳转，使用 enter/leave 事件控制场景媒体。不要直接修改引擎管理的 transform。需要改变场景结构时遵循当前版本支持的重新初始化流程。
- 常驻 UI 放在变换画布外。提供前后、总览和清楚的章节入口；支持键盘，触屏控件有足够尺寸。只添加作品需要的控件。
- 输入框与原生媒体控件使用时避免劫持方向键/空格。隐藏场景不能继续抢焦点或声音；导航后正确管理焦点，提供素材替代文字与影片字幕/文本说明。
- 进入影片场景默认提供明确的播放动作，遵守浏览器自动播放限制。离开时暂停；返回时按内容决定保留或重置进度。检查声音和全屏。长影片不要未经评估嵌入 base64。
- 检测 `prefers-reduced-motion` 并让导航仍然可用；支持无动画切换。JS/引擎不可用时展示有序可读内容。不要只依赖隐藏全部未激活场景的 CSS。
- 本地保存字体、媒体和运行时；离线承诺必须经过网络禁用/断网条件的实际验证。不要用 `file://` 下不可靠的 fetch/module 作为双击即用的交付依赖。需要本地服务器时由 Agent 启动并提供直接预览入口，明确最终交付方式。
- 不依赖庞大前端框架；按作品需要组织 HTML/CSS/JS。内容重复时使用单一场景数据源生成，避免 JSON、HTML 与备注互相漂移。

## 验收循环

先按[快速修改流程](fast-iteration.md)分类。以下完整循环用于新作品或结构性变化；文案/现成截图替换不重新启动整套浏览器验收。

1. 检查 HTML、场景引用、默认路径和本地素材存在性；运行项目已有的 lint/build 等相关检查。不要为低风险文字调整新增脆弱测试。
2. 用真实浏览器打开作品，按默认路线走完，包括影片、分步揭示与结束。
3. 验证章节直达、返回总览、键盘、触屏控件及问答跳转后的继续讲述。确保入口不会落到空画布。
4. 含箭头或连线时，执行 [连接器专项验收](connectors.md)，在字体就绪后检查线身、尖端、文字间距与实际方向；零检查对象不能算通过。
5. 在实际演示尺寸与窄屏预览，检查文字、溢出、遮挡、总览关系、图片裁切与媒体比例。检查控制台错误和资源失败。
6. 检查减少动态效果模式与必要的静态降级；声称离线可用前实际验证离线。
7. 预览→评审→修复→复验。后续小改只复验受影响内容与关联导航；结构性修改重新检查完整路径。

在 review 中记录日期、实际环境、覆盖场景、已知缺口和必要截图。不能测试的项目列为待验证，不能用截图宣称完成播放或键盘测试。交付时给出当前作品入口和简短结果，不向用户倾倒实现细节。

## 已复现的导航冲突

在 step 内自定义跳转按钮时，阻止点击继续冒泡到引擎的默认点击导航，否则可能刚跳转又返回当前 step。自定义键盘导航前检查当前版本内置插件绑定 keydown 还是 keyup；两端重复处理会一次跳过两幕。用真实按键验证，不能只调用 goto 证明键盘通过。

## 手绘动作能力边界（Demo 已验证）

impress.js 原生支持镜头平移、缩放、CSS三维旋转和指定节点跳转。同一图的左右放大与回到全局可以使用共享 SVG 画布和多个空镜头 step，避免复制内容。SVG stroke-dashoffset 支持画圈、箭头与轮廓描绘；CSS配合手写字体支持逐字显现。这些是补充层，不是 impress.js 原生笔迹引擎。真实逐笔汉字书写需要字形笔画路径，不能将淡入/逐字出现称为逐笔书写。CSS三维旋转不等于完整3D建模，任意自然语言动作不能承诺无条件实现；收到需求时映射原生、补充或需专项验证。
