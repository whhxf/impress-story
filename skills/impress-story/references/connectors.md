# 箭头、连线与圈注的几何约束

用于包含流程、关系、循环或手绘标注的空间演示。手绘感来自线条与构图，关系方向和文字可读性仍须准确。

## 已复现的错误与原因

| 错误 | 原因 | 应改为 |
| --- | --- | --- |
| 短箭头像钩子 | 对很短的线仍套用固定弯曲幅度和大箭头尖 | 短连线优先直线，尖端按可用长度缩小；空间不足先重排 |
| 斜向、左向或弯曲箭头朝错 | 箭头尖套用固定向右坐标，没有使用末端方向 | 按线条末端切线生成或使用自动朝向的 SVG marker |
| 连线压住节点文字 | 把节点中心当落点，未扣除节点边界与空隙 | 从源节点外缘出发，在目标节点外缘之外结束 |
| 换字体后又压字 | 按字数猜宽度，或保留上一版字体/字号的坐标 | 字体就绪后测实际边界，更新换行、节点尺寸及端口 |
| 循环回线穿过标签 | 只连通起终点，没有规划整条路径与独立入口/出口 | 先留回线走廊，再安排文字，检查整条曲线和箭头尖 |
| 走完演示仍漏问题 | 导航、字体或总览截图通过，被误当成几何通过 | 将连接器专项检查列入含连线作品的验收 |

这是生成和验收方法的缺口，不能归因于 impress.js 不支持，也不能靠“手绘本来不规整”解释。

## 从关系到几何

1. 明确方向：A 指向 B 表示什么？无方向的关系用普通线，不加箭头。
2. 先排文字与节点，再选端口。连线与圈注在依赖它们的内容确定后生成。不要把“两个坐标连起来”当成完成关系表达。
3. 测真实边界。等待 `document.fonts.ready`，确认字体加载与字形覆盖，再读取 SVG `getBBox()` 或 DOM 实际边界。字体名存在不代表所有字形都正确。边界需额外计入描边、字号增强与视觉留白。
4. 使用同一坐标系。跨嵌套 SVG 变换时，用矩阵把线和文字转到共同坐标系；不能混用屏幕坐标、世界坐标和局部坐标。
5. 从节点边缘选出口和入口，保留清楚空隙。文字不是可穿过的路径区域；无可用通道时，移动节点、扩容或换行，不是让箭头穿字，也不优先缩小文字。
6. 共用连接器函数，让线身与尖端来自同一套起终点/控制点数据。把箭头与普通描边、圈注分开标记，以便诊断。

## 方向与长度

- 直线末端方向为 `end - start`。
- 二次贝塞尔末端方向为 `end - control`；三次为 `end - lastControl`。
- 归一化方向后，尖端两翼从终点向后延伸，再沿垂直方向展开，不能固定写成向右的三点折线。
- SVG `marker-end` 搭配 `orient="auto"` 也可；检查 marker 的 `refX/refY`、大小与终点是否一致。不要混用两种方案画出双重尖端。
- 尖端不能占据大半条短线，也不能缩到投屏看不见。若无法同时满足，增加节点间距，或改为无箭头的短关系线。
- 控制点不应制造意外回头、尖点或末端方向翻转。循环回线可以弯，但最后一段必须明确指向目标。
- 起终点重合、末端切线接近零、不可逆变换，均应视为几何错误，先修再展示。

本次作品采用尖端长度不大于线距的28%、最高15个局部单位，是实例参数，不是所有作品的固定标准。

## 文字、圈注与投屏

长标签优先合理换行或加宽节点，再重新居中并计算边界。圈注不套用箭头规则：围绕目标短语留白，不能划掉字或碰到邻近短语；文字紧邻时先给被强调短语留空间。副标题、截图边框与手绘注释也要检查相互遮挡。

留白应随局部缩放、描边与观看尺寸调整。本次8个局部单位的文字保护区不是跨作品通用值，更不是远距离投影效果的保证。

## 专项验收

新作品、连接器几何或相关文字边界发生变化时，按影响范围执行。只改与连线无关的标题或备注，不触发全图复验；简单文案遵守快速修改流程。

含语义连线的作品，在对应验收时执行：

- 字体加载后检查全部连接器，不只当前一幕。覆盖线身和尖端，检查整条曲线，不只看起终点。
- 确认检查实际发现了连接器；零对象、缺失部件、无字体/边界或变换失败，必须报检查未完成，不能算“零碰撞”。
- 改文字、字体、字号、描边、节点大小、间距或布局后，复验受影响区域及共享连接器调用方。
- 在真实播放尺寸查看短线、斜线、左右向、分叉、汇合、回线和有长标签的场景。再走正常转场，检查中途遮挡及3D视角；静态采样不能代替这一步。
- 保存覆盖范围与结果，分开说明程序检查、实际目视及待验证事项。

可参考 [scripts/audit-connectors.js](../scripts/audit-connectors.js)。它适配分开的SVG线身与V形尖端；页面结构不同时先适配选择器，不能强制所有作品使用此实现。

```js
// 在 ego-browser 脚本中执行；skillPath 为当前 Skill 的绝对路径。
const fs = await import("node:fs/promises");
const source = await fs.readFile(skillPath + "/scripts/audit-connectors.js", "utf8");
const audit = await page.evaluate(source);
console.log(audit);
```

输出 `ok` 才代表该次专项检查通过。路径采样可能漏过小碰撞，包围盒也可能保守误报；按实际字号、缩放与间距设置采样步长。脚本不证明节点含义正确、圈注无误、真实字体字形完整，或投影/3D状态下全部可读。
