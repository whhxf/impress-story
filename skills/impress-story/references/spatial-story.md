# 空间叙事规则

## 选择结构

| 内容关系 | 推荐空间表达 | 避免 |
| --- | --- | --- |
| 总体与组成 | 总览到局部、章节内深入 | 所有内容硬塞成圆形节点 |
| 先后与演变 | 有明确方向的时间线或路径 | 横跨全画布反复折返 |
| 对比与取舍 | 同尺度并列，必要时回到比较视角 | 通过大小暗示未被证实的重要性 |
| 因果与流程 | 有方向、有标签的链路 | 用移动动画代替因果解释 |
| 系统与网络 | 分组、连接和局部聚焦 | 无标签连线与无边界节点堆积 |
| 案例与证据 | 主张→素材→解释→回到主张 | 把画面当成无需解释的证据 |
| 连续论述 | 稳定线性路径，少量章节总览 | 为使用缩放而制造虚假层级 |

同一作品保持空间方向与尺度含义一致。总览展示关系和短标签，不要求细节全文可读；局部则必须能独立阅读并知道所属章节。画布布局以真实包围盒检查遮挡、碰撞和镜头边界，不只凭坐标看起来合理。

## 动作语义

- 放大：进入一个概念的细节。缩小：回到上下文或揭示关系。
- 平移：转到同级主题。远距离跳转优先经过共同上级，或用短转场避免飞越整个画布。
- 旋转：只用于表达视角、方向或内容中的实际空间关系。不要默认复刻官方 Demo 的倾斜文字。
- 渐显：支持分步理解，不能藏住必要信息或让返回路径失效。
- 三维：内容确有必要才使用，先验证可读性与设备表现。

默认文字保持正向，不做连续旋转和极端尺度跳跃。转场时长随距离、场景与反馈调整；“有冲击力”优先通过内容揭示、比例、构图和素材实现。支持减少动态效果，并提供可读的静态降级路径。

## 文案与素材

屏幕文案承担当前结论，讲述备注承担完整解释。素材必须有信息用途；画面复杂时先裁切/聚焦，再配简短标注。中文文本用真实字体和目标尺寸预览，避免细字、小字、密集长段。

用户素材不足不阻断全文结构工作。记录缺口并标记占位，向用户提出具体素材需求，例如“产品打开后的俯视照片，用于说明三个区域”，而不是“给几张图片”。不自动生成或搜集替代真实案例的证据图。


## 让理解发生，而不是只让镜头移动

手绘风格是表现语言，不是固定页面模板。先给每段一个视觉任务，再决定用词、图形和动作：

| 讲述任务 | 画面做什么 | 动作在什么时刻发生 |
| --- | --- | --- |
| 让人关心 | 一个真实的人、具体问题或有信息的提问 | 给听众看清和思考的时间，避免整屏同时出现 |
| 解释选择 | 同一张关系图中的两条路；证据和取舍靠近 | 先让人看到问题，再揭示选择；不用大小暗示未经证实的优劣 |
| 呈现改变 | 保持位置或形状作对照，突出真正变化 | 新信息到来时揭示或圈注，不持续重复绘制 |
| 说明联系 | 同一图的左局部→回全局→右局部 | 缩小让关联变得可见，而不是强制跨章绕路 |
| 留下行动 | 一个观众可以尝试的具体动作或原话中的有力收束 | 节奏放稳，关键句足够大，结束后能停留 |

听众感受到的张力来自真实问题、代价和选择，不来自捏造危机。只有事实支持时才使用数字与强反差。专业培训也可以平静地讲清，不必每段套用戏剧冲突。

首次制作先完成能检验主要设计风险的关键画面；可以是封面、一个解释难点和结尾，不是强制三个页面。把它们连起来看：有没有主次、停顿、揭示、回收？如果只是文字换了、盒子没变，先改构图与内容关系，再展开其余页面。

手绘底座只提供字体、纸色、线条及出现顺序。自由使用留白、画面尺度差异、局部图像和少量强调色；元素数量、标题位置、图片占比随内容变化。字体保持规整、投屏可读；故意画歪箭头、细小文字和无意义摆动不算手绘品质。
